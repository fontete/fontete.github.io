# fontete.github.io

Personal site of Phong Tran, served by GitHub Pages at https://fontete.github.io.

A single static page with no build step: `index.html` holds the markup, styles
and a few lines of JavaScript for the theme toggle and scroll reveal.

| File | Purpose |
|---|---|
| `index.html` | The page |
| `Phong-Tran-CV.pdf` | Public CV (no phone number) |
| `og.png` | 1200×630 link preview image |
| `favicon.svg`, `404.html`, `robots.txt`, `sitemap.xml` | Site basics |

Preview locally with `python3 -m http.server` and open http://localhost:8000.
